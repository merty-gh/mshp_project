# Pocket Budget

Личный трекер расходов и доходов с контролем бюджетов по категориям.

## О проекте

Приложение помогает вести учёт личных финансов: фиксировать доходы и расходы, группировать их по категориям, устанавливать месячные лимиты и отслеживать их выполнение через прогресс-бары.

## Возможности

- **Журнал операций** — список всех транзакций с бейджами дохода/расхода, категорией, суммой и датой.
- **Добавление операций** — форма с выбором типа (доход/расход), категории, суммы и комментария.
- **Контроль бюджетов** — лимиты по категориям с визуальными прогресс-барами и процентом использования.
- **Удаление операций** — с подтверждением через `confirm`.

## Запуск

Требования: Node.js 18+, MongoDB (локально или удалённо).

```bash
cd mshp

# Зависимости
npm install

# Запуск MongoDB (если локально)
# mongod

# Backend (Express, порт 3005)
npm start

# Frontend (Vite, порт 5173)
npm run dev
```

Frontend подключается к `http://localhost:3005` — baseURL задан в `src/main.js`.

## API

| Метод | Путь | Тело | Назначение |
|-------|------|------|------------|
| `GET` | `/api/transactions` | query `?type=expense\|income` | Список транзакций (сортировка по убыванию `_id`) |
| `POST` | `/api/transactions` | JSON | Создать транзакцию |
| `DELETE` | `/api/transactions/:id` | — | Удалить транзакцию |
| `GET` | `/api/categories` | — | Список категорий |
| `PUT` | `/api/categories/:id` | `{ "limit": число }` | Установить лимит категории |

### Модель транзакции

```json
{
  "amount": 500,
  "type": "expense",
  "category": "Продукты",
  "comment": "Хлеб и молоко",
  "createdAt": "25.07.2026 14:30"
}
```

### Модель категории

```json
{
  "_id": "...",
  "title": "Продукты",
  "icon": "",
  "limit": 5000
}
```

## Маршруты

| Путь | Компонент | Описание |
|------|-----------|----------|
| `/` | `HomeView` | Баланс (доходы − расходы) + журнал операций |
| `/add` | `AddTransactionView` | Форма добавления новой операции |
| `/analytics` | `AnalyticsView` | Лимиты категорий с прогресс-барами |

## Глобальные настройки

В `src/main.js`:

- **Axios** — базовый URL `http://localhost:3005`.
- **Day.js** — русская локаль + плагин `relativeTime`.

## Инициализация данных

При первом подключении к MongoDB сервер автоматически создаёт 6 базовых категорий расходов:

| Категория | Лимит |
|-----------|-------|
| Продукты | 0 (не задан) |
| Транспорт | 0 |
| Кафе и рестораны | 0 |
| Развлечения | 0 |
| Жилье и ЖКХ | 0 |
| Другое | 0 |

Доходы используют фиксированный список: Зарплата, Стипендия, Фриланс, Подарок, Прочее.
